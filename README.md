# Astra VPN

اپ اندروید VPN با رابط مدرن (Jetpack Compose) که از رله‌های عمومی VPN Gate استفاده می‌کند.

- **موتور:** SSTP، جاسازی‌شده در همین اپ (برگرفته از Open SSTP Client، مجوز MIT — `app/src/main/java/kittoku/osc`). نیازی به نصب اپ دوم نیست.
- **لیست سرورها:** از شاخهٔ `data` همین ریپو (به‌روزرسانی هر ۳۰ دقیقه با GitHub Actions) و در صورت نیاز از آینه‌های VPN Gate.
- **اتصال خودکار:** در صورت شکست، سرور بعدی را امتحان می‌کند.
- **انتشار:** APK در بخش Releases ریپو ساخته می‌شود.

توجه: رله‌های VPN Gate عمومی‌اند؛ برای کارهای حساس استفاده نکنید.
