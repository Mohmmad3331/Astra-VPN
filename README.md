# Astra VPN

اپ اندروید با رابط کاربری پرمیوم و مدرن (تم تیرهٔ شیشه‌ای، گرادیان بنفش-آبی نئونی) برای استفادهٔ روزمره — یوتیوب، اینستاگرام، ابزارهای هوش مصنوعی و امثال آن.

## چطور کار می‌کند

1. **لیست سرورها:** از API عمومی و رسمی پروژهٔ دانشگاهی [VPN Gate](https://www.vpngate.net) (دانشگاه سوکوبا، ژاپن) گرفته می‌شود — داوطلبانه، رایگان، بدون نیاز به اکانت.
2. **تونل واقعی:** از طریق [External OpenVPN API](https://github.com/schwabe/ics-openvpn/blob/master/doc/API.md) اپ متن‌باز **OpenVPN for Android** انجام می‌شود. این یعنی خود Astra VPN کد بومی (native) OpenVPN را کامپایل نمی‌کند — فقط به موتور آن اپ (که باید یک‌بار نصب شود) دستور اتصال/قطع می‌دهد.
3. رابط کاربری، لیست/رتبه‌بندی سرورها (بر اساس پینگ و سرعت)، و Split tunneling (در حال تکمیل) بخش‌هایی هستند که کاملاً در همین اپ پیاده‌سازی شده‌اند.

## چرا این معماری؟

جاسازی کامل موتور OpenVPN نیاز به کامپایل سنگین کد C/C++ (OpenSSL، mbedTLS و چند کتابخانهٔ دیگر) دارد که بیلدش روی GitHub Actions شکننده و کند است. در عوض از رابط رسمی و سبکی استفاده شده که خود پروژهٔ ics-openvpn دقیقاً برای همین منظور (اتصال از اپ‌های شخص ثالث) منتشر کرده — چند فایل AIDL کوچک، بدون کد بومی.

فایل‌های زیر مستقیماً از آن پروژه کپی شده‌اند (طبق توضیح خودِ پروژه، این فایل‌ها از GPLv2 مستثنی هستند چون دقیقاً برای استفادهٔ اپ‌های دیگر منتشر شده‌اند):
- `app/src/main/aidl/de/blinkt/openvpn/api/*.aidl`
- `app/src/main/java/de/blinkt/openvpn/api/APIVpnProfile.java`

جزئیات در `NOTICE.md`.

## نکتهٔ امنیتی

سرورهای VPN Gate توسط داوطلبان اجرا می‌شوند. برای ترافیک HTTPS معمولی (ویدیو، شبکهٔ اجتماعی، هوش مصنوعی) مناسبند؛ برای کارهای حساس (بانکداری) توصیه نمی‌شود.
